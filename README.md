# raven-mysql

A MySQL client for the [Raven](https://github.com/martian56/raven)
programming language, written in pure Raven. It speaks the MySQL client/server
protocol over `std/net` and does not require a system MySQL client library.

This package is under active development. Its first release will target MySQL
8.x, password authentication, text-protocol queries, safe parameter binding,
and Docker-backed end-to-end tests.
